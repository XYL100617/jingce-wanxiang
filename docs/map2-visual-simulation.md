# 地图2视觉模拟与导航数据边界

地图2的可规划景点、节点 ID、边 ID 和连接关系沿用地图1的 `server/data/scenic_graph.json`。渲染时直接调用 `ScenicOverviewMap.draw`，复用其地图底图、地形装饰、道路和景点建筑 SVG 图层；地图2建筑保留地图1中的绘图锚点和类型，缩小并降低不透明度，导航道路则使用同一批 `layout.edges[edge_id]` 几何并覆盖为更清晰的步行道路样式。路线逐段使用 `/api/navigation` 返回的 `edgeSequence`，路线和底图道路共享节点与几何来源。地图2跟随镜头只改变场景显示视角和比例，不另造一套路网。地图1未显示的图边，仅在规划路线需要时作为模拟连接段显示。模拟资产不参与寻路。

## 视觉参考与处理

- 用户提供的百度地图 2.5D 截图用于参考导航页面的空间层级、倾斜视角、道路与建筑关系、当前位置和转向提示。百度地图网页是动态页面，未从网页提取建筑轮廓或道路坐标。
- 地图2默认保留地图1的北向，跟随位置并根据行进方向留出前方视野；可点罗盘切换为行进方向朝上。导航路线、当前位置、路口箭头和逐段转向提示叠加在地图1对应道路上。地图1继续提供整园推荐路线总览与图例交互，地图2提供近景导航交互。
- 游客自行选择点到点导航时，地图2只突出当前导航路线；个性化推荐路线留在地图1总览，避免两条不同路线交叉造成误读。
- 地图2直接复用地图1中的景点建筑示意图，不再另行猜测每栋楼的落点。建筑在导航视图中做半透明和比例处理，使高亮道路与导航 UI 更突出；建筑外观仍是地图1的模拟插画，不代表真实建筑照片或测绘模型。
- 景点建筑有独立透明点击热区，点击或键盘激活均会打开对应景点卡片，可将该景点设为起点或终点。
- 用户提供的地图1整图和 `deliverables/map2-map1-alignment.md` 是位置与连通关系的约束。
- [中国旅游商贸网景区介绍](https://www.ctsb.com.cn/SceneryShow?ID=17)描述了景区的宋文化和武侠主题建筑；本项目据此采用浅色墙面、木构、深色屋檐等示意风格。该介绍不提供建筑测绘坐标。

## 模拟内容

- 地图1已绘制景点建筑由地图1 SVG 原样复用，未在地图1中绘制的建筑不补画成事实信息。
- 地图1底色和地形装饰来自示意地图；建筑透明度、道路宽度、路径纹理和导航路线高亮为地图2视觉样式。道路中心线取地图1折线。
- 地图1手绘参考小路只以细虚线显示，并标记为未核实、不可规划；穿过地图1水面的参考线不显示。
- 地图2不再沿路线自动散布无名房屋。由于景点到达节点与建筑入口尚未分离，个别建筑体块仍可能接近路线端点；这不能作为现场建筑入口证据。

## 当前导航能力

可自行选择起点和终点，显示分段路线、方向箭头、下一转向和示意剩余路程，并可拖拽、缩放、模拟步行进度与重规划。当前位置是演示位置。地图1道路距离为示意折线估算，尚无实测道路中心线、POI 入口坐标、现场通行规则及定位接入，因此不能用于现场精准导航。
