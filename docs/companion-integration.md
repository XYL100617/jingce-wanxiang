# 陪伴与语音接口接入说明

## GLM 问答

普通景区知识、路线解释和休息建议在允许联网且资料充分时优先尝试已配置的 GLM。儿童模式、安全、紧急事件、天气、排队、开放状态、道路封闭和演出变化等问题按平台规则走本地可信流程。GLM 不可用、输出不符合结构或资料校验失败时使用本地答复。GLM 密钥只放在服务端环境变量；`GET /api/companion` 不返回密钥。

## vivo AI 云语音接口

服务端适配了 vivo 官方 AI 算法平台的语音识别与语音合成协议。当前平台页面只调用 `wss://api-ai.vivo.com.cn/tts` 语音合成服务：游客通过文字提问，勾选授权后可将陪伴回复文字发送给语音合成服务播报。页面不申请麦克风权限、不采集录音，也不调用语音识别接口。服务端生成 `X-AI-GATEWAY-*` HMAC-SHA256 签名头，签名使用 app_id/app_key、时间戳、随机串和规范化查询参数。语音合成使用 `short_audio_synthesis_jovi`，请求 UTF-8 文本的 Base64，接收 24kHz PCM 并封装成 WAV 给浏览器播放；文本超过单次 2048 字节限制时分段合成。陪伴角色映射到 vivo 音色：小明 `xiaoming`、小红 `yunye`、小李 `wanqing`、小王 `yige`、小五 `vivoHelper`。

此接入使用 AI 算法平台的云端语音合成能力。蓝心智能开放平台以及 vivo-ai-lab 的 BlueLM 仓库是其他产品形态，不能与此服务混称。当前会发送陪伴回复文字供云端合成语音；启用前需取得游客对文字播报的授权。应用的语音合成权限、免费额度、额度期限以及超额计费方式需在 vivo 控制台确认；语音识别虽有服务端适配代码，但当前页面不使用。

服务端配置：

```text
VIVO_AI_APP_ID=<vivo开发者平台应用ID>
VIVO_AI_APP_KEY=<vivo开发者平台应用Key>
VIVO_AI_FREE_CONFIRMED=true
```

在 vivo 开发者控制台创建应用并申请语音合成权限后，把应用 ID 和 Key 配在本地服务进程或 Render 环境变量中，再部署重启。只有以上三项有效时，`GET /api/companion/voice` 才返回可用。`VIVO_AI_FREE_CONFIRMED=true` 是操作者确认账号额度后设置的保护开关，不会自动查询或证明免费额度；还应在 vivo 控制台确认额度有效期、超额后的计费规则，并配置可用的消费上限或关闭自动付费。真实联网测试只需在网页勾选语音合成授权并试听文字回复；单元测试用模拟 WebSocket，不代表供应商凭证或免费额度已经验证。
