# 来源分层与地图证据等级

分级判断的是**该字段所引用的原始证据**，不是存储位置。存在于 GitHub 仓库或代码可运行，不会自动成为 T1/T2。无足够证据时填 `UNKNOWN_SOURCE`，同时保持 `UNKNOWN` / `REVIEW_REQUIRED`。结构化值与其来源逐字段关联；混合来源拆成多行。

| 来源层 | 定义 | 最低登记要求 | 本轮已确认登记行 |
| --- | --- | --- | ---: |
| T1 VERIFIED_OPERATOR | 景区/运营方正式提供或确认的 GIS/CAD、通行、演出、封路、闸机、聚合排队/客流 | 授权范围及使用权、提供者和确认人、采集/确认时间、单位、采样方法、缺失说明、有效期、原件快照/哈希 | 0 |
| T2 PUBLIC_VERIFIABLE | 能回到具体官方/许可公开页面核查的公告、日历、开放时间、官方地图、许可开放地图、天气历史 | 准确 URL、查询日期、页面/文件名、许可、有效期、冲突记录、快照/哈希；公开地图线仍需核验是否可步行 | 24（7个独立页面） |
| T3 VERIFIED_ON_SITE | 人工重复走查或景区人员现场确认的入口、道路方向、步行时间、排队、散场 | 核验人、日期、时间、点位/ID、方法、重复次数和误差、照片/轨迹证据、是否双人复核、授权 | 0 |
| T4 SYNTHETIC | 人工规则、仿真预测、mock、排队突增、封路测试、默认营业时间/时长、模拟轨迹 | `synthetic=true`，生成代码/配置、种子和版本、输入、假设、适用范围；只说明模拟与工程流程 | 20 |

当前另有 232 条 `UNKNOWN_SOURCE` 登记行，包括原始图、演示初值及其实体引用；行数不是独立资料份数。T1=0，状态 `CURRENTLY_UNAVAILABLE`：A 当前没有仓库之外的真实运营数据。T3=0，状态 `CURRENT_STAGE_NOT_PLANNED`：本阶段不现场走查。T2 已核验 7 个独立公开页面、登记 24 条字段证据；其许可仍 UNKNOWN，采集者仅在本地保存最小文字摘录且暂不纳入 Git，未保存网页原件，不能升为 T1。T4=20，规则/模拟用途。仓库里出现“公开导览图”和 OSM 字样不足以提升道路等级。

## 地图证据等级

| evidence_level | 需要的依据 | 允许用途 |
| --- | --- | --- |
| `operator_confirmed` | T1 确认的几何、出入口、方向及通行约束，含有效期 | 安全审核通过后，才有资格进入真实导航 |
| `verified_on_site` | T3 现场记录、重复方法和复核证据 | 安全审核通过后，才有资格进入真实导航 |
| `public_inferred` | T2 可追溯公开图/公告推断出的候选线 | 演示和待核验；公开地图线不等于真实可走道路 |
| `visual_only` | 手绘、视觉布局或缺原图/许可的示意线 | 绘图和明确标记的参考演示；不能当真实步行网络 |
| `synthetic` | 规则/脚本构造的测试网络或路线 | 仿真、测试；不能证明真实精度 |

当前 68 条道路的几何统一登记为 `visual_only`：图内标注 `hand_map_reference`，但原图、URL、测绘及授权均 UNKNOWN；不要无证据升为 `public_inferred`。其 `distance_m` 与 `base_travel_time_min` 分别由示意折线和速度假设计算，另在道路表标明 `metric_synthetic=true`。所有 `verified_walkable=UNKNOWN`，代码的 `BIDIRECTIONAL` 也不是现场双向通行证明。坐标既不是米制测量，也不是实测经纬度。只有 `operator_confirmed` 或 `verified_on_site` 在**安全审核以后**才具有未来真实导航资格。

训练准入与导航准入分别判定：任何层级都不能绕过用途许可、个人授权、去标识化、缺失和冲突处理、时间/单位校验与 A/B 签收。T4 可在未来构造明确标签的仿真训练样本，但本轮未生成数据集，也不能把其评价结果解释为真实景区准确率。

## 当前 DEMO 使用边界

图版本 `1.0`、运行模式 `DEMO`。四个园门在演示设定中均可进出，POI 的 `node_id` 是演示到达代理；均未现场核验。当前 68 条道路仍为 `visual_only`、`verified_walkable=UNKNOWN`。未来 REAL 仅在道路及入口/出口达到 `operator_confirmed` 或 `verified_on_site` 并经安全审核后考虑；当前不开启 REAL，也不开展 T3。
